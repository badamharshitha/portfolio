# Harshitha Badam Portfolio

A responsive React and Vite portfolio built with Tailwind CSS and Framer Motion.

## Development

```bash
npm install
npm run dev
```

## Placeholder setup

- Place the real resume at `public/Harshitha_Badam_Resume.pdf`.
- Update the Download Resume link in `src/App.jsx`.
- Update email and LinkedIn values in `src/data/personal.js`.
- Add repository URLs in `src/data/projects.js` when available.
